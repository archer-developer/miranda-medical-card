# 1. Назначение

Medical Service предоставляет встроенный интерфейс командной строки (CLI) для выполнения административных и служебных операций.

CLI предназначен исключительно для разработчика или администратора сервиса.

В отличие от MCP API, CLI предоставляет доступ к внутренним возможностям системы, необходимым для обслуживания, диагностики и миграций.

---

# 2. Почему CLI, а не MCP

Административные операции не являются пользовательскими сценариями.

Например:

- перестроение Embeddings;
- повторная обработка документа;
- переиндексация поиска;
- обслуживание базы данных.

Подобные действия никогда не должны вызываться Miranda и не входят в MCP API.

---

# 3. Архитектурные принципы

CLI использует те же Application Services, что и MCP.

CLI не обращается к Repository напрямую.

Все операции проходят через доменный слой.

Это гарантирует одинаковое поведение независимо от способа запуска операции.

---

# 4. Категории команд

CLI разделяется на несколько логических групп.

- documents
- embeddings
- timeline
- database
- maintenance
- doctor
- users
- statistics

Каждая группа описывается отдельным документом.
